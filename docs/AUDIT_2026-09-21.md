# Adversarial audit — 2026-09-21

Pass-2/Pass-3 audit of this repository. Every claim below was produced by a
command run in this environment on 2026-09-21; the command is given so each
one can be re-run. Nothing here is inferred from the previous README.

Summary: the previously published competition was **fabricated**, and the
"verified data" pipeline that replaced it was built on a **wrong World Series
champion table** which caused authentic postseason data to be thrown away and
replaced by hand-written (partly invented) results. Both are now fixed, and
the system rebuilds end-to-end from two real public sources.

---

## 1. CRITICAL — the published site was generated by `random.*`

`data/*.json` (everything `index.html`/`app.js` renders) was written by
`scripts/generate_mlbcomp_data.py`, seeded with `random.seed(42)`.

Verified evidence:

```
$ grep -n "random\." scripts/RETIRED_generate_mlbcomp_data.py
1084:        weight = random.uniform(0.5, 1.5) / n_seasons
1108:        running_bankroll += step_pnl + random.uniform(-150, 150)
1160:        "avg_edge": round(random.uniform(0.024, 0.048), 3),
1244:        model_prob = round(random.uniform(0.53, 0.62), 4),
1334:    gm = random.choice(HISTORICAL_MATCHUPS)
1339:    odds_val = -110.0 if ... else random.choice([-130.0,-145.0,120.0,110.0])
1340:    is_win = random.random() < (st["win_rate"] / 100.0)
1364:        "model_prob": round(random.uniform(0.53, 0.61), 4),
1367:        "clv_pct": round(random.uniform(-0.5, 3.2), 2),
```

It invented moneylines, totals, probable starters, model probabilities, edges,
CLV, win/loss results, "actual scores", bankroll paths and Kalshi
bid/ask/liquidity/fills — then stamped every record
`"verification_status": "VERIFIED_PRIMARY"`. It also invented *sources*
(`SRC_COORS_HUMIDOR` "Colorado Rockies Humidor Telemetry Archive",
`SRC_PINNACLE_ARCHIVE` "Pinnacle Sharp Closing Line Mirror",
`SRC_CIRCA_SPORTS` line tracker) rated "4.9/5 VERIFIED_PRIMARY"; none is a
real programmatic feed.

Its own summary did not match the files it wrote:

| summary.json claim | actual file |
|---|---|
| 89,452 bets | 1,200 in `bets_ledger.json` |
| 12,480 Kalshi trades | 120 in `kalshi_trades.json` |
| 184 upcoming / 184 open | 165 / 165 |
| environment bets sum 91,090 | ≠ 89,452 |

**Fix:** generator retired to `scripts/RETIRED_generate_mlbcomp_data.py` with a
do-not-run header. The only writer of `data/*.json` is now
`mlbcomp/web/export_static.py`, which reads `data/mlbcomp.db`.

## 2. CRITICAL — the champion table was wrong in 5 of 11 seasons

`mlbcomp/ingest/baseballr.py::KNOWN_WS_CHAMPIONS` listed:

| season | was in code | documented champion |
|---|---|---|
| 2016 | LAD | **CHC** (Cubs over Indians 4-3) |
| 2020 | TB | **LAD** (Dodgers over Rays 4-2) |
| 2021 | HOU | **ATL** (Braves over Astros 4-2) |
| 2023 | LAD | **TEX** (Rangers over Diamondbacks 4-1) |
| 2024 | NYY | **LAD** (Dodgers over Yankees 4-1) |

Cross-checked against four independent public listings that agree on every
season (mlbschedule.net, baseballnewsplus.com, surprisesports.com,
baseballstandard.com).

This wrong table was used as the "independent cross-check" that concluded the
data mirror's postseason was *fabricated*. The README's headline example —
"a '2016 World Series' Cubs-Indians game dated 2016-10-25 that never occurred"
— describes **World Series Game 1 of 2016, which did occur**. The source was
never fabricated; the check was.

## 3. CRITICAL — the replacement corpus contained invented results

Because the mirror was believed fake, 2019-2024 postseason games were replaced
by `mlbcomp/data_recon/po_results.py`, hand-written "reconstructed winners".
Those were themselves wrong, e.g.:

| asserted in po_results.py | actual |
|---|---|
| 2020 WS: TB beat LAD 4-2 | LAD beat TB 4-2 |
| 2021 WS: HOU beat ATL 4-2 | ATL beat HOU 4-2 |
| 2023 WS: LAD swept TEX 4-0 | TEX beat ARI 4-1; LAD was not in the Series |
| 2024 WS: NYY beat LAD 4-1 | LAD beat NYY 4-1 |
| 2019 NLCS: STL beat WAS 4-2 | WAS swept STL 4-0 |
| 2019 WS: WAS won 4-1 | WAS won 4-3 |

The backtest settled postseason bets on these labels, so every postseason
number in the previous README (WC +40.9%, WS −12.0%, experiment A-E results)
was computed against invented outcomes.

**Fix:** `features/po_corpus.py` rewritten to take the postseason from the
mirror — 440 real games, 2015-2025, real scores — and to **raise** unless the
corpus reproduces all eleven documented champions. `po_results.py` is retired
(no longer imported).

## 5. HIGH — 2020 Division Series modelled as best-of-three

`round_needed` returned 2 wins for the 2020 DS in three places
(`ingest.baseballr.round_needed`, `verify.checks._need`,
`engine.backtest._need`). MLB's own 2020-07-23 announcement and the data
itself (the 2020 ALDS `2020|DS|AL|2` has 5 games) show it was **best-of-five**.
The 2020 expansion lengthened the *wild card* round to best-of-three; the DS
kept its normal length.

This corrupted clinch/elimination series-state features. Once the
verification check was allowed to fail, it caught this immediately:

```
series_format_verified   FAILED  2020|DS|AL|1: 4 games > max 3; 2020|DS|AL|2: 5 games > max 3
no_play_after_clinch     FAILED  2020|DS|AL|1; 2020|DS|AL|2; 2020|DS|NL|1; 2020|DS|NL|2
```

After the fix: 0 length violations, 0 play-after-clinch, 113 series.
The same pass also fixed the 2015 single-game wild card in the backtest copy
(it was treated as best-of-three).

## 6. HIGH — verification "passed by recording"

`mirror_po_fabrication_quarantined` was hard-coded `passed=True`, so the suite
reported 16/16 while the data underneath was wrong. It is replaced by
`mirror_po_structural_integrity`, which reports the real counts and fails on
real violations, and `ws_champions_verified` now checks the **mirror** (the
data actually used) and fails on mismatch.

## 7. HIGH — the documented backtest entry point did nothing

`python -m mlbcomp.engine.backtest` (the command in the README) exited 0 and
printed nothing: the module had no `__main__` block. It now runs the
competition and prints the per-environment summary.

## 8. MEDIUM — assumed prices were indistinguishable from real ones

`engine/strategies.py` writes `p_mkt = 0.5` into `bets.market_price` for any
game with no observed price, so `market_price` is never null and a naive
export labels every wager "verified". 14,590 games have real prices; the rest
do not. `export_static.py` therefore resolves provenance from
`data/features/odds.parquet`, not from that column, and labels each wager
`VERIFIED_PRICE` / `ASSUMED_PRICE_PLUS100` / `SYNTHETIC_LINE`.

## 9. Exporter defects found and fixed while building it

* `bets.result` stores `'W'/'L'/'P'`; the first version filtered on
  `'WIN'/'LOSS'` and silently produced a **null win rate for every strategy**.
* Postseason picks carry `status='EVAL'` (unpriced) — filtering on
  `SETTLED` made every postseason row blank even though their games are
  finished. Both priced and unpriced decided picks now count for model-skill
  win rate; only real-price rows count for ROI.
* `json.dumps` emitted bare `NaN` tokens, which are invalid JSON and would
  make every `fetch(...).then(r => r.json())` on the site throw. The exporter
  now sanitises and writes with `allow_nan=False`.
* Compounded quarter-Kelly bankroll (one totals strategy reaches 7.0e9 from a
  1e4 start) is no longer published as a headline number.
