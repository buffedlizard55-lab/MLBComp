METHOD

Methodology

Point-in-time contract

For decision time T, features may use only observations whose availability time is at or before T. Training, validation and out-of-sample test partitions are chronological. Postseason Game 3 can use Games 1–2, never Game 4.

Price and execution contract

American odds are converted to implied probability and de-vigged only for a verified two-way book. Kelly is capped per strategy bankroll. A quote without timestamp, source observation, bid/ask or available size where applicable is not a fill. Missing historical odds produce EVAL or PROPOSED records, never an invented +100.

Postseason hierarchy

Career or multi-year information can inform a postseason prior; current season, late season, prior postseason, current postseason and current game evidence update it with shrinkage. Wild Card, DS, LCS and WS have their own model versions and experiments.

Safety

This repository has no real-money order connector. Kalshi is optional market research only. No output should be interpreted as betting advice.
